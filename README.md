# Faculty Atlas
Public international-teacher resource hub. China, physics and technology focus.

Publish this folder as the root of a new public GitHub repository, with main as its default branch. Under Settings → Pages → Build and deployment, select GitHub Actions. The included workflow publishes after a push or manual run and refreshes articles daily at 00:17 UTC (08:17 Asia/Shanghai). GitHub schedules can be delayed and may be disabled after 60 days of repository inactivity.

No secrets, API keys, ChatGPT sign-in or server are required. Latest Raspberry Pi Foundation RSS article titles, dates and original links are saved in status.json. Failed refreshes retain prior articles and expose the error. Source availability checks do not verify vacancy availability. Job applications and alerts happen on the original providers.
